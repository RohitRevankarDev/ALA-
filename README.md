# AME 5151 - Applied Linear Algebra Lab, Assignment 1

`vector.py` contains the `Vector` class and its statistical methods: `mean`,
`demean`, and population `std`.

`test_vector.py` contains the standard-library unit tests for those methods.

Run the tests from this directory with:

```sh
python -m unittest -v
```

If pytest is installed, you can also run `pytest -v`.
